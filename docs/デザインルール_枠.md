# ピンクの強調枠

- 淡いピンクは、鑑定の要点と安心のメッセージに目が向くように使う。該当する人の要約・本命・月柱・結びつき・五行鑑定と、鑑定を受け取るときの短い安心の一言に使う。
- 一般的な定義、図の読み方、入力上の注意には使わない。本文に添える小さな注記、折りたたみ、用語ずかんへのリンク、白地のカードで案内する。
- トップの入力枠や表・図・操作部品の配色は、情報の区別や操作状態を伝えるために使う。ガイドの現在位置と用語ずかんのリンク先は紫の輪郭で示す。
- 鑑定結果の中に用語の一般解説は並べない。解説は用語ずかんへ

| 画面 | 該当する表示 |
| --- | --- |
| 個人鑑定 | `.sum-item`（`#fff0f5`）、`.card.featured`（`#f4b4cc` の枠）、`.reassure`（`#fff0f5`）、本人に該当する `.stage-card`、`.unki-block`、`.rel-card`（`#fffafc` と `--line`）。節入り注意と用語パネルは枠を外した。 |
| 相性鑑定 | `.sum-item`、`.rel-card`、`.gogyo-reading`（`--hl: #fff0f5`）。一般解説用の `.explain` は削除し、該当する用語へのリンクを結果の下に置く。 |
| トップ・ガイド・用語ずかん | トップは白い `.card` を基本とする。ガイドの `.tour` と用語ポップアップの `.qpop` は白地と薄紫の枠。 `.guide-hl` と `.term:target` は紫の位置表示。ずかんの定義や図は白地。 |
